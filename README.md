# Meraj Safari

Robotics and industrial IoT engineer. Head of IoT & Robotics at Rapid Solutions International (Dubai).
I build the software that connects, tests and diagnoses industrial robots, and I publish the tooling as open source.

## Open-source work

**ABB Robot Web Services (RWS) family** — independent, not affiliated with ABB

- [abb-rws-client](https://github.com/ichbinmeraj/abb-rws-client) — TypeScript client for RWS 1.0 and 2.0 with one API across RobotWare 6, 7 and 8. 763 tests, including live protocol and chaos-proxy suites. Published on npm.
- [abb-rws-vscode](https://github.com/ichbinmeraj/abb-rws-vscode) — RAPID Live, a VS Code extension that connects to live IRC5 and OmniCore controllers: 705-entry RAPID reference, live variable values, execution control, I/O, event log, backup and restore.
- [abb-rws-ros2](https://github.com/ichbinmeraj/abb-rws-ros2), [abb-rws-conformance](https://github.com/ichbinmeraj/abb-rws-conformance), [abb-rws-mcp](https://github.com/ichbinmeraj/abb-rws-mcp), [abb-rws-daemon](https://github.com/ichbinmeraj/abb-rws-daemon) — the next layers on the same client: a ROS 2 supervisory bridge, a public RWS compatibility matrix, a safety-gated MCP server and a local daemon. Early stage; designs published.

**Fairino cobots**

- [fairino-fws](https://github.com/ichbinmeraj/fairino-fws) — REST + WebSocket gateway for Fairino FR-series controllers: live telemetry, bounded motion, program management, fault dumps, telemetry recordings, Prometheus metrics, a hardware-free simulator. Published on PyPI.
- [fairino-fws-console](https://github.com/ichbinmeraj/fairino-fws-console) — operator console for FWS with a 3D arm view, jogging, programs, I/O, force readout and fault decoding.

**IoT**

- Pulsebloom — Python IoT framework with pluggable backends, bidirectional RPC and digital-twin state. Published on PyPI.
